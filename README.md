## Tecnologías presentes en mis proyectos

- **Aplicaciones móviles:** Flutter, Dart, SwiftUI y SwiftData.
- **Web:** React, Astro, TypeScript y JavaScript.
- **Automatización y CLI:** Python.
- **Servicios:** Firebase Authentication, Cloud Firestore, Supabase y Agora.
- **Control de versiones:** Git y GitHub.
